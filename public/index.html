    Study area

    Kohat District lies south of Peshawar in Kohat Division of Khyber Pakhtunkhwa. Kohat city is the district headquarters, and the Indus Highway (N-55) reaches it from Peshawar through the Kohat Tunnel.

    Data and method

    The points were collected on 13 November 2026 from three sources, checked against the district outline in PostGIS, and loaded into the database.

    Sources

    • HBL branch locatorBranch names and coordinates listed for the Peshawar region, kept where they fall inside Kohat District
      12 branches
    • Allied Bank locatorBranches and off-site ATMs listed under Kohat, with address, phone and hours
      7 points
    • OpenStreetMapFeatures tagged amenity=bank or amenity=atm, downloaded with the Overpass API
      5 points
    • BoundariesDistrict and tehsil relations from OpenStreetMap
      5 outlines
    • Population2023 census counts from the Pakistan Bureau of Statistics
      4 tehsils

    Checks before loading

    • Each point was tested with ST_Within against the district outline. Two Allied Bank listings, the Bannu Road and Hangu Road branches, were left out because their published coordinates fall outside Kohat District.
    • Three HBL banks in OpenStreetMap sat within 60 m of HBL locator points. They were merged with those points instead of being added twice.
    • Where a source gives no ATM, phone or opening hours, the field is left empty and the pop-up says it is not listed.
    • One ATM beside MCB Bank KDA has no operator in OpenStreetMap, so its bank is stored as "Not recorded".
    Get GeoJSON

    Database and API

    PostgreSQL with PostGIS stores the data. A small Express API turns each request into a parameterised SQL query and sends the result back as GeoJSON.

    How a request works

    1. BrowserThe page calls /api/points with the current filters.
    2. ExpressThe route checks the filters and builds a query with numbered parameters, so input never becomes SQL.
    3. PostGISST_AsGeoJSON converts each point, and a view adds the tehsil with ST_Within.
    4. LeafletThe GeoJSON comes back and is drawn as markers with pop-ups.

    Endpoints

    • GET /api/points (opens in a new tab)All points. Filters: type, bank, tehsil, q
    • GET /api/points/1 (opens in a new tab)One point by id
    • GET /api/nearest?lat=&lng= (opens in a new tab)Closest points with distance in metres
    • GET /api/study-area (opens in a new tab)District and tehsil outlines with population, area and point count
    • GET /api/summary (opens in a new tab)Counts by bank, type and tehsil
    • GET /api/health (opens in a new tab)Database and PostGIS versions
